# sistema de gestion de informacion y manejo de bases de datos
Solucion de taller para la unidad 3 y 4 de informatica 1, para validar conceptos y la capacidad de usar las herramientas aprendidas, ademas de la habilidad al uso de Python y GitHub.

## Requisitos y Ejecución
- Python 3.x y pymongo (`pip install pymongo`)
- Ejecutar con: `python main.py`
